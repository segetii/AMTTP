\section*{1. Security-First Engineering Philosophy}
Because the AMTTP protocol handles real financial transactions on public blockchains, a single vulnerability could result in catastrophic loss of user funds. As the sole architect, I embedded security at every layer of the stack --- from OWASP-aligned API hardening in the Python/TypeScript backend, to formal static analysis of every Solidity smart contract before deployment.

This document demonstrates the rigorous, automated security auditing pipeline I built to ensure the AMTTP smart contracts meet institutional-grade security standards.

\section*{2. Slither Static Analysis (Automated Vulnerability Detection)}
I integrated \textbf{Slither} (the industry-standard Solidity static analyser developed by Trail of Bits) into a continuous auditing pipeline. Slither performs deep taint analysis, control-flow inspection, and vulnerability pattern matching against the full AMTTP contract suite --- \textbf{38 Solidity files} including the UUPS proxy, the Policy Manager, the Dispute Resolver, and the ZK-NAF verification module.

\section*{3. Echidna Fuzz Testing (Property-Based Verification)}
Beyond static analysis, I configured \textbf{Echidna} (a property-based fuzzer) to generate thousands of randomised transaction sequences against the smart contracts, verifying that critical invariants (e.g., ``no unauthorised oracle can submit a risk score'') hold under adversarial conditions. This level of security testing is typically only performed by dedicated audit firms charging \$50,000+.
